# Alloy updates

`latest.txt` tells the free Alloy cymbal player (Collingwood Cymbals) which version is newest and where to download it.
Alloy reads it about once a day and shows "UPDATE x.y AVAILABLE" in its header when a newer version exists.
Nothing about the user is sent.

Downloads: https://cymbalsamples.com

`strata/latest.txt` does the same for the Strata delay plug-in (Strata 1.0 and later).
